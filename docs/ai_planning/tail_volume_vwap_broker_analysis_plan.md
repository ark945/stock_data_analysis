# 尾盤放量站上均價線 (VWAP) 與分點籌碼逆向歸因策略規劃書

## 一、 策略核心精神與商業邏輯

在台股市場中，「尾盤（13:00~13:30）股價維持在均價線（VWAP）之上且主動外盤放量大買」是主力進場承擔隔夜風險（Overnight Risk）的直接特徵。
雖然台灣證交所盤後分點進出明細**沒有時間戳（Time-stamp）**，但透過**「分時成交均價」與「分點買進均價」的逆向空間配對**，能以極高信心水準還原主力身份與背後動機。

本規劃旨在建立一套從「盤中/盤後分時動能篩選」到「分點身份逆向歸因」，最終產出「次日明確作戰決策」的完整量化管道。

## 三、 三階段核心分析引擎

### 第一階段：尾盤動能雷達 (Tail Momentum Screener)
定義符合「尾盤異動」的候選標的名單：
1. **均價健康度 (VWAP Health)**：
   $$\text{VWAP Gap} = \frac{\text{收盤價} - \text{VWAP}}{\text{VWAP}} \times 100\% \quad (設定在 +0.5\% \sim +3.5\%，避免嚴重過熱)$$
2. **尾盤放量佔比 (Tail Volume Ratio)**：
   $$\text{Tail Ratio} = \frac{\text{13:00~13:30 成交量}}{\text{全日總成交量}} \ge 20\% \sim 35\%$$
3. **主動買盤侵略性 (Buyer Aggression)**：
   $$\text{Outer Market Ratio} = \frac{\text{尾盤外盤成交量}}{\text{尾盤總成交量}} \ge 65\%$$
4. **流動性門檻 (Liquidity Filter)**：
   全日成交量 $\ge 1,000$ 張，成交金額 $\ge 3,000$ 萬元（排除無量炒作股）。

---

### 第二階段：分點均價逆向歸因引擎 (Reverse Broker Attribution Engine)
解決「分點資料無時間戳」的痛點，透過均價與成交量進行匹配：

1. **價格契合度 (Price Proximity Score)**：
   * 取得該股票最後 30 分鐘的成交均價區間 $[P_{tail\_low}, P_{tail\_high}]$ 與尾盤均價 $\bar{P}_{tail}$。
   * 計算特定券商分點當日的買進均價 $\bar{P}_{broker}$。
   * 計算偏離度：
     $$\text{Dev} = \frac{|\bar{P}_{broker} - \bar{P}_{tail}|}{\bar{P}_{tail}}$$
     * 若 $\text{Dev} \le 0.8\%$：極高機率於尾盤進場。
     * 若買均價與早盤或低檔相近：則屬於全日低接，排除尾盤急拉主謀。
2. **成交量貢獻度 (Volume Contribution)**：
   $$\text{Coverage} = \frac{\text{該分點當日淨買超股數}}{\text{尾盤 13:00~13:30 總成交股數}}$$
   * 若單一分點覆蓋率 $\ge 40\%$，或前三大分點覆蓋率 $\ge 70\%$，判定為**「高度集中吸籌拉抬」**。
3. **純買超係數 (Buying Purity)**：
   $$\text{Purity} = \frac{\text{買進股數} - \text{賣出股數}}{\text{買進股數} + \text{賣出股數}}$$
   * $\text{Purity} \ge 90\%$：純留倉建倉，無當沖對敲干擾。

```
│   ├── vwap_tail_detector.py        # 尾盤均價與爆量篩選運算器
│   └── tick_aggregator.py           # 逐筆/5分K彙總工具
├── chip_attribution/               # [擴充] 籌碼逆向歸因模組
│   ├── reverse_broker_matcher.py    # 均價與量能權重匹配歸因演算法
│   └── broker_persona_db.json       # 主力行為標籤庫 (隔日沖/波段/地緣分點)
├── reports/
│   └── tail_ignition_report.py      # 次日作戰手冊報告產製 (整合至 Email/Excel)
└── docs/
    └── ai_planning/
        └── tail_volume_vwap_broker_analysis_plan.md # 本規劃書
```

### 落地三步走：
1. **第一階段（邏輯驗證與指標成型）**：
   * 先以現有 Parquet 盤後資料庫，提取過去已知「尾盤急拉飆股」案例，比對主力均價與日K漲幅，驗證逆向歸因公式的準確度。
2. **第二階段（產製「次日開盤決策表」）**：
   * 整合現有 `cloud_report_generator.py`，每日傍晚產製報表時，新增一頁專屬的「尾盤放量主力歸因雷達」，列出標的、尾盤推手分點與次日操作建議。
3. **第三階段（回測與參數調優）**：
   * 回測過去 1~3 年該策略的次日開盤溢價、早盤高點勝率，產出最佳停利與止損參數。
