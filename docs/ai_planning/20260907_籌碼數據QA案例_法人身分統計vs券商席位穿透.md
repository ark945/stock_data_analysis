## 📌 問題場景 (Problem Scenario)

在 2026 年 9 月 7 日盤後，使用者比對外部財經新聞與 `myStock` 籌碼戰情室卡片時發現數值差異：

### 1. 外部主流財經媒體報導 (Yahoo股市 / 永豐金證券 / 旺得富理財網)：
* **三大法人合計買超台積電 (2330)**：**`16,488 張`**，估計金額 **`405.6 億元`**。
* **各法人明細**：
  * **外資**：買超 **`+16,135 張`**（買進 18,969 張、賣出 2,833 張，估計金額近 400 億元）。
  * **投信**：賣超 **`-368 張`**。
  * **自營商**：買超 **`+720 張`**。

### 2. `myStock` 籌碼戰情室「🌐 外資與本土法人」聚合卡片：
* **機構合計淨買超**：**`+381.17 億元`**
* **合計買超張數**：**`15,570.5 張`**
* **收納席位**：8 家巨型機構席位
* **頭號重押席位**：摩根大通（+93.06 億元，純度 93%）

### 3. 使用者疑問：
> **「為什麼卡片上的 15,570.5 張（381.17 億）與新聞上的 16,488 張（405.6 億）或外資 16,135 張有差距？」**

## 🧠 深度原理解析 (Root Cause & Methodology)

這不是系統運算錯誤，而是台股籌碼架構中**「投資人身分統計（黑盒子）」**與**「券商分點席位穿透（白盒子）」**的根本機制差異。

```
┌─────────────────────────────────────────────────────────────┐
│ 證交所『三大法人買賣超日報』(新聞數據來源：16,488 張 / 405.6 億) │
├─────────────────────────────────────────────────────────────┤
│ 統計維度：投資人開戶「身分證號 / 統編」分類歸戶 (黑盒子)    │
│ • 外資身分戶：買超 16,135 張 (散落於全台 800+ 券商分點)    │
│ • 自營商身分戶：買超 720 張                                │
│ • 投信身分戶：賣超 -368 張                                 │
└──────────────────────────────┬──────────────────────────────┘
                               │ 96.5% 高度集中於外商主力專屬席位
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ myStock『外資與本土法人席位表』(戰情室數據：15,570.5 張 / 381.17 億) │
├─────────────────────────────────────────────────────────────┤
│ 統計維度：實體券商分點席位代碼 (Broker Trade Data 白盒子)   │
│ • 7 大華爾街外商專屬席位：13,349.5 張 / 326.88 億          │
│ • 1 大本土法人總部專戶 (元大總公司)：2,221.0 張 / 54.29 億 │
│ • 合計：8 大主力核心席位共 15,570.5 張 (381.17 億)          │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 差異來源拆解 (差額 564.5 張, 約 3.5%)

1. **外資賣超分點相抵（證交所身分 netting）**：
   * 證交所公布的外資 16,135 張是「全外資買進 - 全外資賣出」之後的淨額。
   * 例如當天**「1560 港商野村」**在台積電賣超 `-540.9 張`（-13.25 億元）。在證交所身分統計中，這 541 張會抵銷其他外資的買超；而 `myStock` 外資買超榜聚焦於「主力重押點火方」，不會拿別家賣超去扣除買方的攻擊力道。
2. **本土券商散落之外資帳戶**：
   * 境外機構法人或特定外資客戶亦可能在永豐金、富邦、國泰等本土券商一般營業部分點開戶下單，身分統計雖屬「外資」，但席位並非 12 大外商專屬分點。
3. **量化過濾門檻 (Noise Filtering)**：
   * 系統為排除零星雜訊，設定外資席位單股淨買超門檻為 `>= 0.5 億元`（5,000 萬元），未達門檻的微量席位不會納入。
4. **新聞標題合計三大法人 (涵蓋投信與自營商)**：
   * 新聞標題之 `405.6 億元 / 16,488 張` 包含自營商（+720 張）與投信（-368 張），並非純外資數字。

## 💡 總結與量化應用價值

* **高達 96.5% 的主力吻合度**：  
  `myStock` 抓到的 15,570.5 張與外資總買超 16,135 張比例高達 **96.5%**，證明當天外資 400 億資金絕非散落各處，而是高度集中於這 7 家華爾街大行與元大總公司。
* **白盒子作戰優勢**：  
  傳統看三大法人日報只能得知「外資買很多」；而透過 `myStock` 席位穿透，操盤者能直接洞悉：
  1. 摩根大通在 2,448.4 元砸了 93 億，且純度高達 93%（幾無賣出，純純鎖碼）。
  2. 美林買了 32 億，需注意隔日沖短線賣壓。
  3. 元大總公司（內資大咖）同步重押 54 億，呈現「外內資共振點火」。
