# myStock 雲端籌碼戰情室 (Chip Intelligence War Room) 整合規劃書

## 一、 整合願景與系統定位

本專案 (`stock_data_analysis`) 擁有強大的量化運算與分點穿透能力（**主力四週期 5/10/20/60日連續吸籌總表**、**主力出貨逃離與散戶接盤下車表**、**尾盤 VWAP 逆向歸因**、**外資各大席位與本土法人部重押解密**），過去僅透過 Email 與 Excel 交付，缺乏直覺、互動、隨身攜帶的現代 Web 體驗。

使用者現已擁有線上運行之股票追蹤雲端平台：
👉 **myStock 線上版**：[https://ark945-mystock.hf.space](https://ark945-mystock.hf.space)  
（技術棧：Hugging Face Spaces + Docker + Supabase 雲端資料庫 + 深色玻璃擬態 UI）

## 二、 資料流與資料庫設計 (Supabase Schema)

原專案核心的**「四週期吸籌模型 (5/10/20/60日)」**與**「主力出貨下車模型」**完整對應為 Supabase 專屬資料表：

### 1. `daily_chip_summary` (每日大盤主力多空速覽)
```sql
CREATE TABLE daily_chip_summary (
    trade_date DATE PRIMARY KEY,
    bull_champion_broker TEXT,      -- 今日多頭司令分點 (如 國泰-敦南)
    bull_champion_amt NUMERIC,      -- 買超金額 (億元)
    bull_champion_stocks TEXT,      -- 核心買超標的 (如 台積電、台達電)
    bear_champion_broker TEXT,      -- 今日空頭調節分點 (如 摩根大通)
    bear_champion_amt NUMERIC,      -- 賣超金額 (億元)
    bear_champion_stocks TEXT,      -- 核心調節標的
    market_sentiment TEXT,          -- 多空氛圍 (偏多 / 震盪 / 偏空)
    total_signals_count INT,        -- 今日觸發訊號總數
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 2. `chip_accumulation_signals` (主力四週期吸籌總表：5 / 10 / 20 / 60日)
```sql
CREATE TABLE chip_accumulation_signals (
    id BIGSERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,
    period_days INT NOT NULL,           -- 吸籌週期：5 (短線點火) / 10 (雙週波段) / 20 (月波段川湖) / 60 (季線長莊)
    symbol VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50) NOT NULL,
    market VARCHAR(10) NOT NULL,        -- 上市 / 上櫃 / 興櫃
    broker_id VARCHAR(10),
    broker_name VARCHAR(50) NOT NULL,   -- 主力券商分點名稱 (如 富邦-新店、台灣摩根士丹利)
    net_amt_yi NUMERIC NOT NULL,        -- 週期累計淨買超金額 (億元)
    net_vol_sheets NUMERIC NOT NULL,    -- 週期累計淨買超張數 (張)
    buy_avg_price NUMERIC,              -- 主力加權買進成本均價
    close_price NUMERIC,                -- 最新收盤價
    cost_deviation_pct NUMERIC,         -- 成本偏離度% ( (現價-主力成本)/主力成本*100 )
    buy_purity_pct NUMERIC,             -- 買進純度%
    concentration_pct NUMERIC,          -- 分點買盤集中度%
    backtest_win_rate NUMERIC,          -- 該標的歷史訊號回測勝率%
    backtest_avg_return_pct NUMERIC,    -- 該標的歷史訊號平均報酬率%
    persona_tag VARCHAR(50),            -- 主力標籤 (波段長莊 / 隔日沖 / 本土法人)
    action_guide TEXT,                  -- 次日實戰作戰指引
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 索引：支援前端快速切換週期
CREATE INDEX idx_accum_date_period ON chip_accumulation_signals(trade_date, period_days);
CREATE INDEX idx_accum_symbol ON chip_accumulation_signals(symbol);
```

### 3. `chip_exit_signals` (主力出貨/逃離與散戶接盤下車表)
```sql
CREATE TABLE chip_exit_signals (
    id BIGSERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,
    exit_type VARCHAR(30) NOT NULL,     -- 週期或型態：5d出貨 / 10d調節 / 20d出清
    symbol VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50) NOT NULL,
    market VARCHAR(10) NOT NULL,
    dump_broker_name VARCHAR(50) NOT NULL,  -- 出貨大戶分點名稱 (如 凱基-台北)
    dump_amt_yi NUMERIC NOT NULL,       -- 淨賣超金額 (億元)
    dump_vol_sheets NUMERIC NOT NULL,   -- 淨賣超張數 (張)
    sell_avg_price NUMERIC,             -- 大戶出貨加權均價
    close_price NUMERIC,                -- 最新收盤價
    retail_broker_name VARCHAR(50),     -- 主要接盤之散戶券商分點
    warning_level VARCHAR(20),          -- 預警等級 (🚨 高危險出貨 / ⚠️ 震盪調節)
    action_guide TEXT,                  -- 防禦與停損指引
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_exit_date ON chip_exit_signals(trade_date);
CREATE INDEX idx_exit_symbol ON chip_exit_signals(symbol);
```

### 4. `broker_institution_ranks` (外資各大席位與本土法人部重押表)
```sql
CREATE TABLE broker_institution_ranks (
    id BIGSERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,
    category VARCHAR(20) NOT NULL,      -- 'FOREIGN' (外資席位) 或 'DOMESTIC_INST' (本土法人)
    broker_name VARCHAR(50) NOT NULL,   -- 券商席位名稱 (如 台灣摩根士丹利、國票-敦北法人)
    symbol VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50) NOT NULL,
    market VARCHAR(10) NOT NULL,
    net_amt_yi NUMERIC NOT NULL,
    net_sheets NUMERIC NOT NULL,
    buy_avg_price NUMERIC,
    buy_purity_pct NUMERIC,
    feature_tag VARCHAR(50),            -- 屬性標籤 (如 💎 波段機構主力 / 🎯 絕對鎖碼)
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 5. `vwap_attribution_signals` (尾盤放量站上 VWAP 歸因表)
```sql
CREATE TABLE vwap_attribution_signals (
    id BIGSERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,
    symbol VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50) NOT NULL,
    market VARCHAR(10) NOT NULL,
    close_price NUMERIC NOT NULL,
    vwap_price NUMERIC NOT NULL,
    vwap_premium_pct NUMERIC NOT NULL,  -- 溢價%
    broker_name VARCHAR(50) NOT NULL,   -- 尾盤推手分點
    broker_buy_avg NUMERIC NOT NULL,    -- 分點均價
    net_amt_yi NUMERIC NOT NULL,
    net_vol_sheets NUMERIC NOT NULL,
    buy_purity_pct NUMERIC NOT NULL,
    persona_tag VARCHAR(50),            -- 隔日沖急拉 / 波段主力高位鎖碼
    action_guide TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 三、 myStock 前端「籌碼戰情室」UI/UX 規劃

延續 myStock 原生高級深色主題（Dark Theme + 玻璃擬態 Glassmorphism）：

### 1. 頂部一級分頁導覽
* `📊 自選追蹤 (現有)`
* `🏛️ 籌碼戰情室 (NEW ⭐)`
* `📈 市場概況 (現有)`

### 2. 籌碼戰情室子導覽與核心功能模組

#### 🌟 Tab 1: 【今日旗艦戰情速覽】
* 頂部多空儀表條：今日多方司令 vs 空頭調節之王（含各自買賣前三名標的）。
* 今日最精選 3 大主力卡片（今日最狂吸籌標的、明日隔日沖避坑清單、地緣內部人警報）。

#### 📥 Tab 2: 【主力四週期吸籌總表】(核心武器 ⭐)
* 提供**子切換按鈕 (Pill Segment Control)**：
  `⚡ 5日短線點火` ｜ `🔥 10日雙週波段` ｜ `💎 20日月波段 (川湖模式)` ｜ `🏰 60日季線長莊`
* 點擊任一週期，卡片列表秒級刷新：
  * 卡片顯示：股票代號/名稱、市場別（上市/櫃/興）、主力分點名稱、累計買超金額（大紅字）、買均價 vs 現價成本偏離度、買進純度%、集中度%、歷史勝率。
  * 支援搜尋代號或股票名稱快速過濾。

#### 📤 Tab 3: 【主力出貨與下車逃離避坑榜】(防禦雷達 🚨)
* 專屬暗紅色警戒區塊：
  * 列出主力在 5d/10d/20d 大舉獲利了結或下車逃離的標的。
  * 顯示：大戶出貨分點、出貨總金額、出貨均價、接盤散戶券商分點（誰在高檔當韭菜）。
  * 作戰指引：標註「高檔出貨宜停利離場」或「跌破成本多殺多警報」。

#### 🌐 Tab 4: 【外資與本土法人席位重押】
* 一鍵切換 `🌐 外資席位排行榜` 與 `🏢 本土法人/總公司專戶榜`。
* 清楚區分「美林 (隔日沖)」與「大摩/高盛 (波段)」，看穿法人主力真實意圖。

#### ⚡ Tab 5: 【尾盤放量站上 VWAP 逆向歸因】
* 每日收盤前放量急拉站上均價線 (VWAP) 的股票，並標註是「隔日沖拉尾盤想倒貨」還是「波段主力最高價掃貨」。

#### 🔍 跨模組穿透：自選股籌碼即時透視
* 使用者在原本的自選股清單中，如果該股票今日觸發「吸籌」或「出貨」，卡片自動亮起徽章 `[🔥20日吸籌]` 或 `[🚨大戶出貨]`。
* 點擊直接彈窗查看該股票在 5/10/20/60 日各週期的主力分點加權成本線！

## 四、 本專案 (`stock_data_analysis`) 整合改造工程

本專案只需新增一個輕量模組 **`sync_to_mystock.py`**：

1. **依賴套件**：
   * `requests` 直接呼叫 Supabase REST API（無需安裝肥大 SDK，零環境負擔）。
2. **運作邏輯**：
   * 讀取現有運算產出的所有 DataFrame：
     - `df_5d`, `df_10d`, `df_20d`, `df_60d` (四週期吸籌總表)
     - `df_exit` (主力出貨下車逃離表)
     - `df_vwap` (尾盤放量 VWAP 歸因表)
     - `df_foreign`, `df_inst` (外資與本土法人席位表)
   * 轉為標準 JSON 格式。
   * 以 Supabase 的 `POST /rest/v1/...` 搭配 `Prefer: resolution=merge-duplicates` 進行秒級 Upsert。
3. **雲端排程全流程整合 (`main_cloud_runner.py`)**：
   * 在每日排程運算完成後自動執行：
     ```python
     if os.getenv("SUPABASE_URL") and os.getenv("SUPABASE_KEY"):
         sync_to_mystock(trade_date, ...)
     ```
   * 隨後發送 Telegram 訊息：
     > 🏛️ **本日台股主力情報已同步至 myStock 戰情室！**  
     > 👉 [立即點此在手機開啟戰情室](https://ark945-mystock.hf.space)

## 五、 實施效益與對比

| 評估維度 | 舊模式 (Email + Excel) | 新模式 (myStock 雲端戰情室) |
| :--- | :--- | :--- |
| **載體媒介** | 每日 4~5 封信箱塞爆，需下載 Excel | 隨時隨地開啟手機瀏覽器即可看盤 |
| **閱讀體驗** | 「Excel 鬼才會看」、手機縮放困難 | 玻璃擬態暗黑卡片，單手滑動秒讀 |
| **吸籌與出貨** | 分散在多個 Excel 工作表或零散信件 | 專屬 Tab 2 (5/10/20/60日吸籌) 與 Tab 3 (出貨下車) |
| **資訊互動** | 靜態死資料，無法篩選或聯動自選股 | 支援按鈕切換、搜尋、點擊穿透主力成本線 |
| **自選股整合** | 需手動在 Excel 搜尋自己買的股票 | myStock 自選股自動標記主力重押警報 |
| **維護成本** | 需維護多個郵件模板與附件 | 統一由 Supabase 資料庫驅動，乾淨優雅 |
