# myStock 雲端籌碼戰情室 (Chip Intelligence War Room) 整合規劃書

## 一、 整合願景與系統定位

本專案 (`stock_data_analysis`) 擁有強大的量化運算與分點穿透能力（主力四週期重押、出貨逃離雷達、尾盤 VWAP 歸因、外資/本土法人席位解密），但過去僅透過 Email 與 Excel 交付，缺乏直覺、互動、隨身攜帶的現代 Web 體驗。

使用者現已擁有線上運行之股票追蹤雲端平台：
👉 **myStock 線上版**：[https://ark945-mystock.hf.space](https://ark945-mystock.hf.space)  
（技術棧：Hugging Face Spaces + Docker + Supabase 雲端資料庫 + 深色玻璃擬態 UI）

### 系統分工架構：

## 二、 資料流與資料庫設計 (Supabase Schema)

由於 `myStock` 本身已原生整合 Supabase，因此**「透過 Supabase 做為資料同步匯流排」是成本最低、速度最快、體驗最流暢的解法**。

### 1. `daily_chip_summary` (每日大盤主力多空速覽)
```sql
CREATE TABLE daily_chip_summary (
    trade_date DATE PRIMARY KEY,
    bull_champion_broker TEXT,      -- 今日多頭司令分點 (如 國泰-敦南)
    bull_champion_amt NUMERIC,      -- 買超金額 (億元)
    bull_champion_stocks TEXT,      -- 核心買超標的 (如 台積電、台達電)
    bear_champion_broker TEXT,      -- 今日空頭調節分點 (如 摩根大通)
    bear_champion_amt NUMERIC,      -- 賣超金額 (億元)
    bear_champion_stocks TEXT,      -- 核心調節標的
    market_sentiment TEXT,          -- 多空氛圍 (偏多 / 震盪 / 偏空)
    total_signals_count INT,        -- 今日觸發訊號總數
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 2. `chip_smart_money_signals` (主力核心標的訊號庫)
```sql
CREATE TABLE chip_smart_money_signals (
    id BIGSERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,
    symbol VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50) NOT NULL,
    market VARCHAR(10) NOT NULL,        -- 上市 / 上櫃 / 興櫃
    strategy_type VARCHAR(30) NOT NULL, -- 5d點火 / 10d雙週 / 20d月波段 / 尾盤VWAP / 出貨逃離
    broker_id VARCHAR(10),
    broker_name VARCHAR(50) NOT NULL,   -- 主力分點名稱
    net_amt_yi NUMERIC NOT NULL,        -- 淨買超金額 (億元)
    buy_avg_price NUMERIC,              -- 主力買進均價 (成本線)
    close_price NUMERIC,                -- 當日收盤價
    cost_deviation_pct NUMERIC,         -- 成本偏離度%
    buy_purity_pct NUMERIC,             -- 買進純度%
    persona_tag VARCHAR(50),            -- 主力屬性 (波段長莊 / 隔日沖 / 本土法人)
    action_guide TEXT,                  -- 次日實戰作戰指引
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 建立索引加速 myStock 前端查詢
CREATE INDEX idx_chip_signals_date_strat ON chip_smart_money_signals(trade_date, strategy_type);
CREATE INDEX idx_chip_signals_symbol ON chip_smart_money_signals(symbol);
```

### 3. `broker_institution_ranks` (外資席位與本土法人部排行)
```sql
CREATE TABLE broker_institution_ranks (
    id BIGSERIAL PRIMARY KEY,
    trade_date DATE NOT NULL,
    category VARCHAR(20) NOT NULL,      -- 'FOREIGN' (外資) 或 'DOMESTIC_INST' (本土法人)
    broker_name VARCHAR(50) NOT NULL,   -- 券商席位名稱 (如 台灣摩根士丹利)
    symbol VARCHAR(10) NOT NULL,
    stock_name VARCHAR(50) NOT NULL,
    net_amt_yi NUMERIC NOT NULL,
    buy_avg_price NUMERIC,
    buy_purity_pct NUMERIC,
    feature_tag VARCHAR(50),            -- 屬性標籤 (如 隔日沖 / 積極建倉)
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 四、 本專案 (`stock_data_analysis`) 整合改造工程

本專案只需新增一個輕量模組 **`sync_to_mystock.py`**：

1. **依賴套件**：
   * `supabase` 或直接使用 `requests` 呼叫 Supabase REST API（無需重型 SDK，完全相容現有環境）。
2. **運作邏輯**：
   * 讀取現有運算產出的 DataFrame（`df_5d`, `df_10d`, `df_20d`, `df_exit`, `df_vwap`, `df_foreign`, `df_inst`）。
   * 將精華數據轉換為標準 JSON 格式。
   * 以 Supabase 的 `POST /rest/v1/...` 搭配 `Prefer: resolution=merge-duplicates` 進行秒級 Upsert。
3. **雲端排程全流程整合 (`main_cloud_runner.py`)**：
   * 在每日運算完成後，自動執行：
     ```python
     if os.getenv("SUPABASE_URL") and os.getenv("SUPABASE_KEY"):
         sync_to_mystock(trade_date, ...)
     ```
   * 隨後發送 Telegram 訊息：
     > 🏛️ **本日台股主力情報已更新至 myStock 戰情室！**  
     > 👉 [立即點此在手機開啟戰情室](https://ark945-mystock.hf.space)

## 五、 實施效益與對比

| 評估維度 | 舊模式 (Email + Excel) | 新模式 (myStock 雲端戰情室) |
| :--- | :--- | :--- |
| **載體媒介** | 每日 4~5 封信箱塞爆，需下載 Excel | 隨時隨地開啟手機瀏覽器即可看盤 |
| **閱讀體驗** | 「Excel 鬼才會看」、手機縮放困難 | 玻璃擬態暗黑卡片，單手滑動秒讀 |
| **資訊互動** | 靜態死資料，無法篩選或聯動自選股 | 支援按鈕切換、搜尋、點擊穿透主力成本線 |
| **自選股整合** | 需手動在 Excel 搜尋自己買的股票 | myStock 自選股自動標記主力重押警報 |
| **維護成本** | 需維護多個郵件模板與附件 | 統一由 Supabase 資料庫驅動，乾淨優雅 |
