# 5日與10日跨週期主力動能加速度分析規劃 (Cross-Period Momentum Intelligence)

## 1. 背景與核心目標
目前系統之「四週期連續重押吸籌雷達」在 5日（短線點火）、10日（雙週波段）、20日（月波段川湖）、60日（季大戶）四個週期中，採用獨立運算與各自排序的方式呈現。
然而，單一週期的指標僅能反映「總量（Volume）」，無法揭示主力在時間軸上的「進出加速度與節奏（Cadence & Acceleration）」。

例如 2887（台新新光金）在 5 日累計淨買超 10.40 億，在 10 日累計淨買超 10.44 億：
- 數值表面上看相似，但跨週期比對揭示：**99.6% 的買盤全數集中在最近 48 小時內爆發**！
- 這代表主力並非長期溫吞慢買，而是受特定重大催化劑驅動的「突發急行軍搶籌」。

本功能旨在不新增任何資料庫表格、不新增任何排程批次的原則下，於記憶體中自動完成 5日 vs 10日（及延伸20日）的跨週期動能比對，自動為個股標註動能型態與專屬實戰指引。

---

## 2. 動能型態分類與量化數學模型

以個股＋主力分點為鍵值 $(Symbol, Broker)$，計算動能加速度佔比：
$$R_{5/10} = \frac{\text{近 5 日淨買超金額}}{\text{近 10 日淨買超金額}} \times 100\%$$

| 動能型態 | 判斷條件 | 籌碼行為意義 | 實戰指引 (Action Guide) |
| :--- | :--- | :--- | :--- |
| **🚀 突破急行軍** | $R_{5/10} \ge 80\%$ 且 成本乖離 $\le 12\%$ | 主力於成本附近發動暴買急行軍，剛起步突破 | 時效爆發力極強，可沿主力加權成本防守布局 |
| **🚨 高檔乖離急行軍** | $R_{5/10} \ge 80\%$ 且 成本乖離 $> 12\%$ | 短線暴買但現價已偏離成本過大，慎防竭盡誘多 | 提防高檔竭盡買盤或拉高誘多，切忌盲目追高，留意爆量長黑停利 |
| **💎 破發逆勢急行軍** | $R_{5/10} \ge 80\%$ 且 成本乖離 $< -5\%$ | 主力於成本下方逆勢暴買加碼，護盤反彈強烈 | 具高性價比安全防守點位，主力自救強烈 |
| **🌊 勻速波段建倉** | $40\% \le R_{5/10} < 80\%$ 且 乖離 $\le 15\%$ | 兩週內每天穩定持續吃貨，籌碼結構最健康 | 標準機構法人波段認養，適合沿雙週均線順勢持有 |
| **🌊 波段高檔推升** | $40\% \le R_{5/10} < 80\%$ 且 乖離 $> 15\%$ | 主力持續勻速買超，但股價已推升至高乖離區 | 持股者沿均線移動停利，空手者切勿市價追高 |
| **⚠️ 買盤已熄火** | $R_{5/10} \le 20\%$ 或 近5日轉賣超 | 10日總額看似龐大，但近5日買盤近乎停滯 | 主力吃飽收手待散戶抬轎，嚴禁追高，破線停損 |
| **⚡ 游資高檔搶短** | 前段無底倉 且 成本乖離 $> 10\%$ | 短線熱錢或隔日沖高檔搶短，極易反手倒貨 | 嚴格落實當日/隔日停利，避免留倉接刀 |
| **⚡ 游資短點火** | 前段無底倉 且 成本乖離 $\le 10\%$ | 低檔極短線熱錢或隔日沖快速點火 | 適合超短線順勢快進快出，宜設嚴格移動停利 |

## 3. 架構與實作設計

### 3.1 零架構負擔原則
1. **純記憶體運算**：在 `main_cloud_runner.py` 產出 `df_5d` 與 `df_10d` 後，直接以 Pandas DataFrame 執行 merge 與比對，耗時 $< 0.05$ 秒。
2. **零 Schema 變更**：
   - HTML/Excel 報表：直接於「股票標的 / 吸籌特徵」動態生成彩色膠囊徽章。
   - Supabase 資料庫：直接將成果存入現有的 `persona_tag`（主力屬性標籤）與 `action_guide`（作戰指引），既有前端網頁無需改動即可自動顯示。
