# myStock 戰情室動態 K 線圖與懸浮籌碼 HUD 實作計畫

## 1. 目標概述
為 `myStock` 戰情室所有股票標的（四週期吸籌、主力出貨、外資法人、VWAP 突擊、衍生資券）建立點擊展開 **動態 K 線圖彈窗 (Interactive K-Line Modal)**，並支援 **滑鼠懸停 (Mouse Over / Crosshair) 即時浮動資訊卡 (Floating HUD Tooltip)**，將技術面 K 線與籌碼面「主力加權成本線、點火日起算日」完美疊加融合。

> [!IMPORTANT]
> **使用者核心要求**：
> 1. 本次實作 **零資料庫 (Supabase) 結構變更**，**零歷史補檔工作**。
> 2. **先在本地端 (Local) 啟動展示與驗證**，待使用者明確確認「OK / 完成」後，才執行 Git 提交與推送到遠端。

---

## 2. 架構設計與互動體驗

```mermaid
graph TD
    A[戰情室任意個股卡片] -->|點擊卡片或 📈 按鈕| B[開啟暗黑玻璃擬態 Modal]
    B -->|前端即時請求| C[Yahoo Finance / TWSE 公開日K API]
    C -->|回傳 1 年 (250D) OHLCV| D[TradingView Lightweight Charts 繪圖引擎]
    D --> E[渲染 K 線圖 + 成交量柱狀圖]
    D --> F[畫出金色虛線: 主力加權成本價]
    D --> G[標註火箭 🚀: 主力點火日]
    E -->|Mouse Over 游標懸停| H[即時 HUD Tooltip 懸浮面板]
```

### 核心功能清單：
1. **TradingView Lightweight Charts 4.x 金融級繪圖引擎**：
   - 輕量（僅 45KB），毫秒級加載，極致流暢的縮放 (Zoom) 與拖曳 (Pan)。
   - 支援 4 種時間視窗快速切換：`[ 3個月 (60D) ]`、`[ 半年 (120D) ]`、`[ 1年 (250D) ⭐預設 ]`、`[ 2年 ]`。
   - 自動繪製 3 條關鍵均線：**MA20 (月線)**、**MA60 (季線)**、**MA250 (年線)**。
2. **籌碼專屬疊加圖層 (市面唯一特點)**：
   - **金色水平虛線**：`主力加權成本線`（帶價格標籤與偏離率，例如 `主力成本: $40.8 (+1.1%)`）。
   - **點火起算日標記**：在主力首度大額建倉的 K 棒下方標註 `🚀 主力點火`。
3. **滑鼠懸停 (Mouse Over) 即時連動 HUD 資訊面板**：
   - 當游標移到任一根 K 棒上時，懸浮面板即時聯動：
     - 日期、星期
     - 開盤、最高、最低、收盤、漲跌幅、成交量
     - 均線數值 (MA20 / MA60 / MA250)
     - 與主力成本價之現價偏離度 (%)

## 3. 實作步驟規劃

### 第一步：引入圖表庫與彈窗 HTML/CSS
- 修改 `d:\MyProject\stock_data_analysis` 下或 `myStock` 前端靜態資源。
- 在 HTML 加入 TradingView Lightweight Charts CDN。
- 新增 `#klineModal` 玻璃擬態彈窗結構（含圖表容器、頂部股票資訊、週期切換按鈕、HUD 資訊欄、關閉按鈕）。
- 加入符合現有戰情室風格的科技暗黑風 Modal 樣式、懸浮 HUD 標籤樣式。

### 第二步：編寫前端 K 線載入與繪圖核心邏輯
- 編寫 `fetchStockKline(symbol)` 函式，透過前端非同步抓取 Yahoo Finance 台股歷史日 K（支援 `.TW` 上市與 `.TWO` 上櫃）。
- 編寫 `openKlineModal(stockData)` 函式：
  - 初始化圖表，載入 K 線與成交量。
  - 計算 MA20、MA60、MA250 均線。
  - 繪製主力成本金色水平線與點火標記。
  - 綁定 `crosshairMove` 事件，驅動 Mouse Over 懸浮資訊面板即時更新。
- 將所有分頁（吸籌總表、出貨下車、外資法人、VWAP、衍生雷達）的卡片綁定點擊事件。

### 第三步：本地端 (Local) 啟動展示與驗證
- 啟動本地測試 Web 伺服器。
- 檢驗卡片點擊、K 線加載、均線計算、主力成本線繪製、Mouse Over 懸浮顯示是否完美順暢。
- 截圖呈現給使用者審閱。

### 第四步：使用者確認後推送
- **嚴格遵守規範**：僅在使用者審閱確認滿意並回覆「OK / 完成」後，才進行 `git add/commit/push`！
