# 權值巨鯨籌碼追蹤矩陣 (Whale Matrix Intelligence) 技術規劃

## 一、 需求背景與問題定義
在現行台股主力日報量化模型中，評分系統 (`score`) 優先加權「買進純度 (如 85%~90%+)」，此設計非常利於挖掘類似「川湖 (2059)」的高純度中小型飆股。
然而，針對千億級權值股（如聯發科 2454、台積電 2330），外資或大型機構分點常伴隨套利、避險等雙向造市，買進純度通常落在 70%~80% 間：
- 例：2026-09-07 美商美林 (1440) 於聯發科 (2454) 近 5 日狂買 **+130.18 億**（全市場金額第 1 名），但因純度 77.9%，在依評分排序的 HTML 日報榜單中落在第 685 名，首頁未能第一時間置頂曝光。
- 同時，大型權值股建倉週期通常涵蓋雙週（10d）與月波段（20d），單看 5 日容易誤把 60 日長莊二次總攻當成短線游資。

## 二、 設計原則
1. **雙軌分流，互不干擾**：
   - 保留原「近 5 日短線點火雷達」專注於高純度中小型潛力飆股。
   - 於日報頂部（或 5 日雷達正下方）增設「🐳 權值巨鯨籌碼追蹤矩陣 (Whale Matrix)」，專門鎖定 5 日淨買超金額 TOP 5 標的。
2. **三維一體，同表穿透 (5d · 10d · 20d)**：
   - 在同一張卡片中，並列展現 5 日（點火）、10 日（雙週加速）、20 日（底倉）之金額。
   - 標註主力動能節奏（急行軍 / 勻速建倉 / 買盤放緩）與戰略操盤定性。
3. **零 DB Migration、零批次排程異動**：
   - 5d、10d、20d 本來就在 `main_cloud_runner.py` 記憶體中，純記憶體組裝，零額外批次與排程負擔。
